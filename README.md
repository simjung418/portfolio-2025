# SJM Portfolio

프론트엔드 개발자 심정민의 포트폴리오입니다.  
실제 서비스 개발 경험을 중심으로 프로젝트와 기술 스택을 정리했습니다.

이 포트폴리오는 기획, 디자인, 개발을 모두 단독으로 수행한 프로젝트입니다.
- UX 구조
- UI 디자인
- 컴포넌트 구조
- 타입스크립트
- 인터렉션 디자인
- 배포

## Tech Stack

- **Framework**: Next.js, React
- **Language**: TypeScript, JavaScript
- **Styling**: TailwindCSS
- **Backend (experience)**: PHP, MySQL
- **Tools**: Git, Figma, Jira, Notion

## Features

- Career 중심 프로젝트 소개
- KPI 기반 경력 요약
- 프로젝트 상세(CAR: Challenge / Action / Result)
- 반응형 UI
- Next.js App Router 기반 구조

## 주요 경험

### 플랫폼 유지보수 및 개발
- 번역 플랫폼 **Lexcloud** 유지보수 및 기능 개선
- 내부 운영 시스템 UI 개선 및 신규 기능 개발

### ISO 27000 시리즈 보안 인증
- 인증 요구사항 분석
- **2FA 인증, 접근 통제 기능 구현**
- QA 및 인증 심사 대응 리딩

### AI 서비스 개발 (DeepRead)
- 논문 분석 AI 서비스 프론트엔드 개발
- 실시간 데이터 기반 UI 구현

### 데이터 시각화 (MetaField)
- Chart 기반 데이터 시각화 대시보드 개발
